## 使用規則

1. **訓練集**：用明文訓練邏輯斯迴歸，得到權重與偏差；每個特徵的平均與標準差也**只能**從訓練集算。
2. **驗證集**：挑出 4 個特徵、調整參數。可以反覆使用。
3. **測試集**：最後只用一次，回報準確率，並比對「明文判斷」與「CKKS 加密判斷」是否一致。用測試集反覆調參，等於偷看答案。

## 欄位（BRFSS 健康調查）

標籤 `Diabetes_binary`：0 = 無糖尿病，1 = 糖尿病前期或糖尿病。其餘 21 個特徵多為 0／1，數值型的有：

| 欄位 | 意義 |
|---|---|
| `BMI` | 身體質量指數 |
| `GenHlth` | 自評健康，1 = 極好 … 5 = 很差 |
| `Age` | 13 級年齡層，1 = 18–24 歲 … 13 = 80 歲以上 |
| `MentHlth`、`PhysHlth` | 過去 30 天心理／身體不好的天數 |
| `Income`、`Education` | 收入 1–8 級、教育 1–6 級 |

0／1 欄位有 `HighBP`（高血壓）、`HighChol`（高膽固醇）、`DiffWalk`（行走困難）、`HeartDiseaseorAttack` 等。4 個特徵由 `training/train.py` 在驗證集上挑選。

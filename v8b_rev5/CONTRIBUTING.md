# Contributing

Thank you for your interest in EdgeFHE.

- Open an issue first for bugs or questions; use the issue templates of the repository.
- Keep the evidence rules of this repository: every published number must point to a source file, failed runs are kept,
  and corrections are added rather than overwriting history.
- Never commit private keys, certificates with private material, personal data, real user inputs, or machine-specific
  paths and addresses. Use the example values already used in this repository (`192.0.2.x`, `C:\work\EdgeFHE`, user `example`).
- Hardware changes need HLS C simulation / co-simulation and routed timing reports; board results must state the board
  build, boot and evidence level they come from.
- By contributing you agree that your contribution is licensed under the Apache License 2.0.
